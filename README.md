## 繁體中文

《龍與地下城》跑團用法術整備助手，支援 2014（5e）、2024（5.5e）混用規則。可管理多位角色、計算兼職與契約法術位、匯入雙面 PNG 卡圖、記錄施法、處理短休／長休，並用 .dndprep 保留戰鬥進度。

- **網頁／離線使用**：下載 docs/index.html 原始檔，用瀏覽器開啟。五種語言可在頁首切換。
- **Windows 11 x64**：解壓縮 Windows ZIP，雙擊 DND_Spell_Prep.exe。使用 Edge 獨立視窗，或以預設瀏覽器顯示本機介面。
- **開始跑團**：先編輯角色和規則，再新增文字或卡圖。啟用回合限制時，請在法術卡設定施放動作，並按「下一回合」切換。用「存檔」保存角色、卡圖、次數和紀錄。

角色自填內容、已存戰鬥紀錄保留原文。若瀏覽器下載存檔，請到下載位置找 .dndprep。角色資料與卡圖在本機處理，無須登入。

## 简体中文

适用于《龙与地下城》跑团的法术准备工具，可混用 2014（5e）与 2024（5.5e）规则。支持多个角色、兼职与契约法术位、双面 PNG 卡片、施法记录及短休与长休。使用 .dndprep 保存进度。

- **离线网页**：下载 docs/index.html 原文件，用浏览器打开。在顶部切换语言。
- **Windows 11 x64**：解压 Windows ZIP，双击 DND_Spell_Prep.exe。界面通过本机 Edge 独立窗口或默认浏览器打开。
- **开始跑团**：编辑角色和规则，再添加文字或卡图。启用回合限制后，在卡片上设置施法动作，换回合时点“下一回合”。用“保存”保留卡片、次数和记录。

自填文本和已有战斗记录保留原文。角色数据与图片在本机处理，无需登录。

## English

A Dungeons & Dragons session utility for mixing 2014 (5e) and 2024 (5.5e) rules. Manage multiple characters, multiclass and Pact Magic slots, two-sided spell card images, casting limits, rests, and combat logs. Resume a session with a .dndprep save.

- **Offline web app:** Download the raw docs/index.html and open it in a modern browser. Change language in the header.
- **Windows 11 x64:** Extract the Windows ZIP and run DND_Spell_Prep.exe. The app opens in an Edge app window or the default browser.
- **At the table:** Set up a character and rules, then add spell text or card images. For turn limits, set each spell’s casting action and use **Next turn** when the turn changes. Use **Save** to keep cards, uses, and the log.

Character data and images are processed locally. Custom text and existing combat entries retain their original language. Some browsers download the save file instead of offering an in-place save.

## 日本語

『ダンジョンズ＆ドラゴンズ』のセッション向けツールです。2014年版（5e）と2024年版（5.5e）のルールを混用できます。複数キャラクター、マルチクラスと契約魔法のスロット、両面呪文カード、発動履歴、小休憩・大休憩に対応し、.dndprep で進行状況を保存できます。

## Build and test

Build the offline HTML with Python 3.10+ and run the app tests with Node.js 20+.

    python3 app/build_web.py
    node tests/app.test.cjs

The Windows x64 build uses x86-64 Linux, GCC, and GNU binutils with the i386pep linker target. The launcher embeds the same offline HTML.

    bash app/build.sh
    gcc -O2 tests/launcher.c -o tests/launcher-smoke
    ./tests/launcher-smoke
    ./tests/launcher-smoke fallback

Edit app/messages.tsv to update translations, then regenerate docs/index.html. The builder checks for incomplete translations and mismatched placeholders.
